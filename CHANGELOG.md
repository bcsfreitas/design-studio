# Changelog

## Unreleased

Planned for 0.4.0: Design Studio’s first supported public beta. Build and explore product ideas with your coding agent in a local workspace you can make your own.

- Create interactive screens, documents, diagrams, and canvases together in a prototype.
- Use design systems to share components, themes, and project context across your work.
- Explore the Feedback Inbox and Marketing examples, including working screens, alternate states, and an annotated handoff canvas.
- Customize the full source code and publish a read-only site for others to try.
- Improved first-visit onboarding, file updates, and permanent links to your work.

This is early beta. Version 0.4.0 establishes the supported baseline; earlier development formats are not supported. Published sites have no built-in sign-in; use your hosting provider’s access controls for private work.

## Earlier development releases

Versions 0.2.0–0.3.0 were development milestones leading to the first public beta. Their detailed history remains in Git.
